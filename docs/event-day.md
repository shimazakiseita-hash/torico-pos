## 開店手順
1. サーバーPC（受付）の電源を入れる。Wi-Fi親機とアプリは自動で起動する
2. 残り3台の電源を入れ、Wi-Fi「TORICO-POS」につながったらブックマークを開く
3. お客さん用の画面を F11 で全画面にし、「音を有効にする」をタップ
4. 管理画面で今日の仕込み数と釣り銭準備金を確認
5. 試しに1件：受付で注文 → 焼き場にカードが出る →「完成」→ 渡し場とお客さん用画面に番号が出る → スマホで整理券のQRを読んで「できあがりました！」を確認 →「渡した」。確認したら渡し場と焼き場の「戻す」で待ちに戻し、受付で取り消す（この1番の整理券は捨てる）

## 営業中
- 受付：注文を入れる → 預かり金額を押す → お釣りを渡す → 画面の番号と同じ整理券を渡す（必ず上から順に）
- 焼き場：右の本数を見て焼く。味付け担当は古い注文から1件ぶんを仕上げて「完成」
- 渡し場：呼び出し中の番号を呼ぶ → 整理券の番号を確かめて渡す →「渡した」
- 取り消した注文の整理券は捨てる（番号とQRがずれないように）
- 売り切れた品は責任者が管理画面で「売り切れ」にする（受付で押せなくなる）
- 1時間ごとに責任者が管理画面からCSVをダウンロード

## トラブル時

| 症状 | 対応 |
|---|---|
| 画面上部に赤い「接続エラー」 | その端末のWi-Fiが「TORICO-POS」につながっているか確認 → つなぎ直してページを再読み込み |
| 全部の端末が接続エラー | サーバーPCがスリープ・電源切れになっていないか確認。電源を入れ直せば自動で復旧する（データは残る） |
| サーバーPCは動いているのにつながらない | サーバーPCで `nmcli connection up torico-ap`、`sudo systemctl restart torico-pos` |
| Wi-Fiが不安定 | サーバーPCを店の中央・高い位置に置く。だめなら `docs/network.md` の代替案（ルーター／有線／テザリング） |
| お客さんのスマホページが更新されない | サーバーPCのインターネット接続を確認（管理画面に警告が出る）。店内の画面は影響を受けないので営業は続け、店頭の呼び出し画面と声で案内する |
| どうしても復旧しない | **紙運用に切り替え**：番号は最後に発行した番号の続きから手書き、注文は紙の表に正の字で記録し、あとでまとめて入力 |

## 閉店後（毎日）
1. 管理画面の「レジ締め」で、レジ内の現金を数えて入力し、理論値との差額を確認
2. CSVを最終ダウンロードして共有フォルダに保存
3. `data/torico.db` をUSBメモリなどにコピー（2日目に備えたバックアップ）
4. 4台の電源を切る。**DBの初期化はしない**（2日目は日付で自動的に切り替わり、番号は1から始まる）

## 2日目の終了後
- 管理画面の「合計」で2日間の売上・本数を確認し、会計報告に使う
- サーバーPCのスリープ設定を元に戻す（`docs/network.md` 4）
