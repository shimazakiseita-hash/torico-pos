# デザイン依頼：やきとり TORI♡CO のスマホページとミニゲーム

焼き鳥屋台「やきとり TORI♡CO」（大学祭「津田沼祭」、2026年11月21日・22日）で、お客さんがスマホで見るページとミニゲームを、もっと完成度の高い見た目にしたい。
**ほしいのはデザインデータ（画面のデザイン案と、絵の素材）**。プログラムは、こちらで組み込む。

## どんなものか
- お客さんは焼き鳥を注文すると、番号入りの整理券をもらう。整理券のQRをスマホで読むと「呼び出し状況」のページが開き、自分の番号が焼いている最中か、できあがったかがわかる。
- 待っている間（数分）に遊べるミニゲームがある。遊ぶと「やきとりポイント」がたまり、ガチャでマスコットの「きせかえ」がもらえる。
- 遊ぶのは大学生・家族連れ・子ども。**1回1〜3分、片手、縦持ち**で遊ぶ。

## 世界観とブランド
- テーマは「**宇宙 × ゆめかわ**」。濃い紫の宇宙に星、ピンクのハート、白い羽、ぷっくりした文字。
- マスコットは「**とりこ**」：白くてふわふわの丸いひよこ。オレンジのとさか、黄色いくちばし、星の目、ほっぺはピンク（画面の写真を参照）。
- ロゴ：「やきとり TORI♡CO」（ハートと羽のついたロゴ。写真を参照）。
- 広報委員会の原本（ロゴ・マスコット・ポスター・メニュー表）は、依頼のときに別に添付する。**原本とずれない**ようにしてほしい。

## 2つのゲーム
**とりこフライト**：画面をタップすると、とりこがはばたく。宇宙のいん石の柱のすきまを抜けて進む。途中で串やアイテムを取る。4ステージ（そらのうえ／つきのうら／ほしくずのうみ／りゅうせいぐん）を抜けるとボス（はらぺこUFO／ゴロゴロいん石／ブラックホール）が出る。

**とりこショット**：画面を引っぱって離すと、とりこが山なりに飛ぶ。お祭りの夜の屋台を背景に、焼き鳥の材料でできた砦を崩して、UFOの手下を全部倒すとクリア。全20面をマップで進み、20面はUFOの親玉（ボス）。飛んでいる途中でタップすると技が出る（どかーん／ぎゅーん／ずしーん／ぶんしん）。
- 砦の材料：ねぎま串（木の柱・板）、炭（重くて硬い）、焼き網（もろい）、焼き台（動かない足場）、つくね（転がる玉）、火種（壊れると爆発）、花火玉（落ちると大爆発）。

## 納品の形
- 絵の素材は **SVG**（いちばんうれしい）か、**透過PNG（上の大きさの3倍）**。1つの部品につき1ファイル。ファイル名は英数字（例：`shot-ufo.svg`）。
- 画面のデザイン案は、幅390のスマホ画面で。画像（PNG）か Figma。余白・文字の大きさ・色がわかるようにしてほしい。
- 新しく色を足したら、色の一覧も一緒に。

## 守ってほしいこと
- ゲームのルール・遊び方は変えない（デザインだけ）。
- **とりこショットのステージ画面の中には、日本語の説明文を入れない**（説明はスタート前のカードだけ。画面の中は絵と動きで伝える）。
- 画面の上の端（面の番号・残りの玉・点数）と下の端（技のボタン）は表示に使っている。ゲームの絵はその間に収める。
- 絵文字は使わない（スマホの機種で見た目が変わるため）。
- 今の画面で気になっている点：
  - フライトのボス戦で、上のHPゲージととりこが重なって見えにくい（11）
  - はじめの画面（03）は情報が多く、初めての人がどこを押せばいいか迷う
  - 効果音が無い（音の素材の提案があればうれしい。必須ではない）
