# TORI♡CO 追加デザイン素材（received-2）

前回の素材は含まず、この追加依頼の新規素材のみ収録しています。

## フォルダ

- `costumes/`: 13種類の小物を **300×286の全面キャンバス** に配置した透過SVGと、3倍の900×858透過PNG。ファイル名の `front` / `back` に従いキャラ画像の前後へ重ねてください。
- `gacha/`: ガチャマシン、レア度別カプセル（閉・上半分・下半分）、光の放射、紙ふぶき、未所持シルエット。
- `shop/`: 3種の強化アイコン（64×64 SVG）。
- `mockups/`: きせかえ・ガチャ・ショップの390×844画面デザイン案。PNGは確認用、SVGは編集用。
- `costume-preview.png`: 公式キャラと13種類を重ねた確認用一覧。素材としてのマスコット本体は含めていません。

## 合成する順番

1. `*-back.svg` の小物（にじいろオーラ、流れ星のしっぽ）。
2. ご自身の `mascot.webp` （300×286、背景透過）。
3. `*-front.svg` の小物（それ以外の11種）。

すべて同一キャンバスなので座標指定なしで重ねられます。前景と背景の2枚を同時につけることもできます。

## 重要：位置合わせの注意

今回は **実際に組み込む `mascot.webp` が未提供** のため、前回の公式JPGの絵柄と縦横比を元に座標合わせをしました。`costume-preview.png` は公式JPGを使った近似合成です。特におでこ・目にかかる `hachimaki` と `sunglasses` は、本番の `mascot.webp` に重ねて最終位置を確認してください。

## 見せ方

- 未所持：灰色の「？？？」ではなく `gacha-locked-silhouette.svg` を使い、入手前はアイコンを半透明にする。形のヒントは残しつつ、正体は出しすぎない。
- ガチャ演出：`gacha-capsule-*-closed` を揺らし、`top`と`bottom`を離して開封。`gacha-rays-*` と `gacha-confetti-*` を後ろと前に重ねる。レア度が高いほど時間・星の数を増やす。
- 小サイズ：きせかえ一覧では `costume` レイヤーをマスコットと同じCSSサイズで描画。20px表示では細線を避け、64px以上で細部を見せる。
- カラートークンは元の `README.md` の指定に従い、追加色は `asset-colors.json` に記載。
- 画面モック内の日本語はデザイン説明用。実装は画像ではなく通常のHTML/CSSテキストで表示してください。

## 変更しないこと

ゲームの点数・ルール・ガチャの確率・必要ポイント・レア度は元のまま。プログラムと公開環境は変更していません。
