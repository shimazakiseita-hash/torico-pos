# TORI♡CO デザイン素材パック

津田沼祭 2026 | スマホ 390×844 / ゲーム論理座標 360×640。

## このパックについて
- `sprites/`: **独立したSVG素材**。背景透過・文字なし。shotは物理サイズに合わせた拡大縮小、flightは指定サイズの目安で使用。
- `backgrounds/`: 5つの縦長背景PNG。ゲーム空間に合わせて中央基準でトリミング。とりこショットの操作可能領域では上部/下部HUDの安全領域を避ける。
- `mockups/`: 390×844の画面案。実装時の文字はCSSで出す（画像に焼き込んで使わない）。
- `originals/`: 依頼者支給の**公式キャラと公式ロゴを無加工で再同梱**。新しいキャラは作っていません。
- `color-tokens.json`: 既存の色指定＋小さな追加色。
- `asset-manifest.json`: 収録素材一覧。
- `sprite-sizes.json`: 各素材のSVG寸法・ゲーム画面上の表示推奨寸法・リピートのヒント。

## 実装時の重要事項
1. **画面のルール、当たり判定、点数、保存、難易度は変更しない**。SVGは描画だけ差し替える。
2. 伸縮する`shot-negima-post`、`shot-negima-beam`は**全体を一様に伸ばさず中央だけリピート**推奨。グラデーションの端は固定。`shot-grill-mesh`の斜線模様はSVG`pattern`で伸縮しても密度が一定。
3. 破損差分は `-crack.svg`。ゲーム内のHP/状態に応じて絵を切り替えるだけ。
4. `flight-meteor-tile.svg` は高さ64を連続リピート、`flight-meteor-cap.svg` を上下端（下は180°回転）に。`flight-meteor-column.svg` は完成イメージ参照。
5. `shot-boss-idle/angry/hit`は同じ表示座標に重ねて切り替える。動きや当たり判定は従来通り。
6. ボタンのSVGは**文字なし**。`Zen Maru Gothic`のテキストを別レイヤーに載せる。
7. 透過SVGは `img` / Canvas `drawImage`で利用可能。端末の高解像度描画は元SVGから適切にラスター化。
8. 背景PNGは元サイズで同梱。モバイル縦長・横長端末に応じ、中央寄せ `cover` とトリミングを想定。

## 5画面の変更意図
- `call-cooking`: 一番大切な番号・焼いている状態・前の組数を優先。下にミニゲームの導線。
- `call-ready`: 完成時は白い大カードとシアンの縁取り、番号を特大に。「受け取り口へ」を強調。
- `hub`: 最初に「とりこフライト」「とりこショット」の2つの大きな遊ぶボタン。ガチャ・ショップ・ランキングはサブ導線。
- `flight-result`: 点数を大きく、自己ベスト比較、やきとりポイント、再挑戦を一本化。
- `shot-map`: 現在のステージが明確。クリア済み・未開放の見た目を区別、スクロール可能に。

## 演出提案（ゲームロジックに影響させない）
- **ショットの爆発**: `explosion-01`→`02`→`03`→`04`、各45〜65ms。背後に白い閃光を1フレーム。ヒットストップは既存のまま。
- **クリア**: `clear-burst`を0.85倍から1.25倍に拡大、200ms、減衰する星くず。音は優しい上昇3音。
- **ボス撃破**: 怒り→被弾差分、300msの小さな揺れ、シアンの星と桃色の星が外へ散る。音は短い低音＋キラキラ。
- **ガチャ当選**: カプセルが左右に3回ゆれてから割れる、`gacha-reveal.svg`を0.2秒フラッシュ。希少度で星の数を変える。
- **ボタン操作**: 押した瞬間に0.96倍、離すと180msで復帰。音は20〜50msの控えめなポップ。消音切替も用意。
